## 4. Known limits, left as they are by decision

- **Won disputes:** the inviter's $5 isn't restored automatically. The team restores it by hand
  (runbook). The session still doesn't count toward ambassador goals.
- **Goal bonuses already paid are never taken back**, even if the sessions behind them are
  later refunded or disputed.
- **A reward already spent isn't taken back** on a refund or dispute (never below $0).
- **Invite claims aren't limited to brand-new accounts.** The server accepts a code from any
  account that has never booked, as long as the code's owner joined first. The app only offers
  the field at sign-up, so this needs a modified app, and the inviter still earns only when
  that person completes a real session.
- **Join date = when the sign-up link was first requested.** Someone who requests a link,
  waits, then verifies after their friend joined is refused that friend's code. Someone else
  requesting a link for an address early makes that account "old" (a nuisance, no gain).
- **The saved invite code lives on the phone that signed up.** Opening the emailed link on a
  different device doesn't apply it. It expires after 14 days.
- **Refunds made outside Stripe** (cash, another channel) don't return credit.
- **`ua.edu` and `crimson.ua.edu` are separate addresses** for the one-invite-per-email rule.
- **`check_invite_code` can be called signed out** and has no rate limit. It only reveals that
  a code exists, never whose.
- **`bookings.platform_fee` overstates noot's real revenue** on credit bookings (the credit
  comes out of noot's share).
- **There's no `trynoot.com/join` page.** Invites send the home page plus the code.
