## Team runbook (Supabase Studio, SQL editor — no admin screen yet)

Every step below is safe to run twice: a second run changes nothing.

**Approve an ambassador** (unlocks goal bonuses and cash-out; pays goals already reached):
```sql
insert into ambassador_approvals (user_id)
select id from users where lower(email) = lower('<their email>')
returning user_id;
```
No row returned = nobody was approved (check the email). They must already have tapped
"Become an ambassador". If they hadn't, the goals pay when they do.

**Pay a cash-out.** Pending requests: `select * from credit_cashouts where status = 'pending';`
Send the money, then:
```sql
update credit_cashouts set status = 'paid', paid_at = now()
 where id = '<cashout id>' and status = 'pending';
```

**Reject a cash-out** and give the credit back (only acts on a pending request):
```sql
with c as (
  update credit_cashouts set status = 'rejected'
   where id = '<cashout id>' and status = 'pending'
  returning id, user_id, amount_cents)
insert into credit_ledger (user_id, amount_cents, kind, cashout_id)
select user_id, amount_cents, 'adjustment', id from c;
```

**Noot won a dispute — give the inviter's $5 back.** DISPUTES ONLY: a full refund also takes
the reward back, and that one should stay taken. A new dispute takes the reward back
automatically (`reward_reversal` rows); winning does not restore it.
```sql
-- gives back what was taken for that booking, once (amount_cents there is negative)
insert into credit_ledger (user_id, amount_cents, kind, booking_id)
select r.user_id, -r.amount_cents, 'adjustment', r.booking_id
  from credit_ledger r
 where r.booking_id = '<booking id>' and r.kind = 'reward_reversal'
   and not exists (select 1 from credit_ledger a
                    where a.booking_id = r.booking_id and a.kind = 'adjustment' and a.user_id = r.user_id);
```
The session still doesn't count toward ambassador goals (`bookings.credit_reversed_at` stays
set). If that matters for someone close to a goal, tell Claude — it needs a small code change.

**Change the goal bonuses:** edit rows in `ambassador_milestones`. Bonuses already paid aren't
changed.
